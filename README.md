# glitchOS — исходники для OnePlus 6T

Экспериментальная система Александра / cfifBOOM на LineageOS 22.2 (Android 15),
устройство **fajita**. Имя помощницы пока не выбрано. Существующие технические
имена `ContourHome`, `vendor/contour` и `app.contouros.home` сохранены.

**В 0.5.0 по просьбе «оставь меня» помощница садится спиной в угол карточки.**
Она спрашивает, можно ли предлагать помощь. Ответ и поза сохраняются после
закрытия диалога и перезапуска. Напиши «вернись» или нажми «Позвать обратно».
Для установки на OnePlus используется подписанная OTA. Из архива исходников
её можно собрать самостоятельно. [Сборка](BUILDING.md) · [Проверки на телефоне](VALIDATION.md)

## Что готово в коде

- Сетка из 4 или 6 малых клеток с размерами плиток 1×1, 2×2, 4×2 и 4×4.
  Рабочий стол читает плитки в сохранённом порядке и ставит каждую на первое
  подходящее место. Поэтому маленькое приложение из конца списка может
  оказаться рядом с калькулятором. Новые приложения добавляются в конец
  сохранённого списка. Рабочий стол запоминает плитки, которые ты убрал вручную.
  Значок растёт вместе с плиткой, для подписи выделено отдельное место.
- Полный список приложений с поиском открывается свайпом влево; возврат — вправо.
  Учтены системные панели, вырез и открытая клавиатура.
- Единственный встроенный HOME — glitchOS. Trebuchet сохранён как поставщик
  Quickstep/Recents, включая жесты и навигацию тремя кнопками.
- Обычный портрет использует исходный рисунок. Для сидящей позы создана
  отдельная иллюстрация по этому образцу. Она неподвижна в правом нижнем углу.
- По нажатию открывается портрет и текстовый диалог. Есть первое приветствие,
  реакция на быстрый возврат, история последних **60 реплик** после перезапуска.
- Команды без интернета: «будильник через пять минут», «через полчаса разбуди
  меня», «поставь будильник на 7:30», отмена и запрос состояния. Если время не
  задано, помощница уточняет его и принимает следующий ответ в течение двух минут.
  Произвольный текст, отрицания и цитаты не становятся действиями.
- Будильник через Android AlarmManager с уведомлением, звуком, вибрацией и
  экраном остановки. Проверены запуск на заблокированном экране и остановка;
  отдельный список остальных проверок и ограничений есть в VALIDATION.md.
- Один собственный активный будильник; состояние и короткий журнал событий
  отделены от личной переписки. Ошибка API не выдаётся за успешную постановку.
- Если ты выбрал «Можно предлагать», при снижении заряда до 15% вне зарядки
  помощница может вернуться с вопросом об энергосбережении. Настройки открываются
  по твоему ответу. При исходно низком заряде она дождётся нового разряда.
  После «Без подсказок» ждёт, пока ты её позовёшь. Условие проверяется при
  показе рабочего стола или диалога.
- Короткий системный сигнал подсказки учитывает режим звонка, вибрацию,
  настройки уведомлений и «Не беспокоить». Будильники используют громкость
  Android для будильников. «Стоп» отзывает разрешение на подсказку,
  останавливает текущий звонок и ставит движение портрета на паузу.
- Подключение к дереву ROM с резервной копией и проверяемым откатом.

Пока **нет свободной LLM-беседы, голоса, чтения переписок, наблюдения через камеру,
универсального исполнителя команд, управления root/ядром или скрытого экрана**.
Ответы на несколько бытовых фраз локальные. Это функциональный первый шаг;
портрет и ограниченный словарь не выдаются за готовый интеллект.

## Статус проверок

Проверены 4 000 раскладок прямоугольных плиток, 69 случаев команд и времени,
13 Python-тестов подключения, отката и защиты существующего дерева. Проходили
компиляция SDK 35 и Soong, установка с исходным сертификатом и проверки на
OnePlus. Подробный статус конкретной сборки хранится в [VALIDATION.md](VALIDATION.md).
Успешная компиляция сама по себе не подтверждает надёжность будильника или OTA.

## Как устроен текущий шаг

| Файл | Назначение |
|---|---|
| `HomeActivity`, `TileBoard`, `HomeStore` | Существующий главный экран и сохранённая сетка |
| `PresenceView` | Отрисовка выбранного персонажа |
| `AssistantActivity`, `ConversationStore` | Ввод, ответы, история в Credential Encrypted storage |
| `OfflineCommand`, `LocalAssistant` | Строго распознанная команда → локальный исполнитель |
| `AssistantAlarm`, `AlarmReceiver` | Планирование, состояние и восстановление будильника |
| `AlarmSoundService`, `AlarmRingActivity` | Звонок и остановка, без доступа к истории с экрана блокировки |
| `tools/Configure-Home.py` | Подключение существующего модуля к product fajita и откат исходников |

Ключи подписи, Updater, recovery и ядро сохраняются. Изменения Quickstep
хранятся отдельным патчем в `patches/lineage-22.2-sole-home.patch`.
Пакет собирается в `/product/app`; специальные системные права для первого
навыка не нужны. После испытаний исполнитель будет выделяться по мере роста
системных функций, а не превращаться в произвольную shell-команду модели.

отдельным этапом после рабочего диалога.

## Проверки без телефона

```bash
python3 tools/Test-Home.py
```

Нужен JDK с компилятором. Для полной компиляции по Android SDK:

```bash
python3 tools/Test-Home.py \
  --android-jar /путь/к/sdk/platforms/android-35/android.jar \
  --build-tools /путь/к/sdk/build-tools/35.0.0
```

В Windows `Build-Home.ps1` собирает отдельный APK с локальным ключом разработки.
Сборщик и `Install-Home.ps1` берут версию из манифеста. Для 0.5.0 проверены
сборка, версия и контрольная сумма APK, а также четыре сценария установщика
с имитацией ADB.
Для обновления системного рабочего стола на OnePlus нужен ключ прошивки.
Каталоги `build`, `.local`, private keys и SDK в архив не входят.
Публичная лицензия собственного проекта пока не выбрана; сторонний код
OAssist/BlueOS в этот выпуск не включён.
